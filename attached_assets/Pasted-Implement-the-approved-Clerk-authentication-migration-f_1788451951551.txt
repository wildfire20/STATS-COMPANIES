7. EXISTING EMAIL USER LINKING
==================================================

If a Clerk-authenticated user has no existing Clerk identity mapping:

1. Retrieve their VERIFIED email from Clerk server-side.
2. Search PostgreSQL for an existing user with that email.
3. If exactly one safe matching existing user exists:
   - link the Clerk identity to that existing PostgreSQL user.
4. If there is no existing user:
   - create a normal PostgreSQL customer record.
   - then create the identity mapping.
5. If multiple/conflicting records exist:
   - DO NOT guess.
   - return a controlled migration error requiring administrator review.

Never grant access using an unverified client-supplied email address.
